## 🌟 Learning Objectives
This course aims to guide students in enhancing performance capabilities across specific stages (such as dance, musical theatre, drama, tech-art, or interactive game experiences) through the integration of interactive visuals and audio. The curriculum covers fundamental programming syntax, AI applications, and external hardware (e.g., MIDI controllers), leading students to integrate music, space, and code logic into a comprehensive practice of Music-Interactive Scenographization.

## 🛠️ Core Technologies & Learning Focus
This project integrates several key technologies during implementation. The functions and parameter mappings for each module are as follows:

| Category | Key Tech / Tools | Description & Application |
| :--- | :--- | :--- |
| **Interactive Hardware** | `MINIS (RtMidi)`, `MIDI Keyboard` | Reads external MIDI signals, capturing values in real-time for 0-1 parameter mapping. |
| **Input System** | `Unity New Input System` | Adopts an event-based architecture for flexible Action Maps and Binding configurations. |
| **Physics & Motion** | `Rigidbody`, `Update()`, `Time.time` | Endows objects with physical properties, achieving smooth dynamics via per-frame updates. |
| **Audiovisual Fusion** | `Particle System`, `AudioSource` | Maps audio frequencies to visual particles and effects to build Generative Art. |

## 📖 Course Overview
The course units and development guidelines cover the following core modules and implementation steps:

### 1. Content Acquisition & System Setup
1. **Unity New Input System**:
   * Learn to transition from the legacy Input Manager to an event-driven system supporting multiple devices.
   * Configure `Input Actions`, Action Maps, Actions, and various Bindings settings.
2. **MIDI Device Integration (MINIS Plugin)**:
   * Install and configure RtMidi and MINIS plugins in Unity to read signals from external MIDI devices (e.g., nanoKONTROL2, nanoPAD2).
   * Capture MIDI values (0-1 range) using `ctx.ReadValue<float>()` for real-time parameter mapping.
3. **Interactive Generative Art**:
   * Trigger and control particle systems (emission, color changes, speed) in real-time via MIDI signals.
   * Integrate AudioSource for interactive audiovisual responses.

### 2. Development & Implementation Guide
1. **Phase 1: Stage & Scenario Definition**
   - Choose a specific stage theme (e.g., tech-art, interactive games, dance visuals) to define the main focus of MIDI interaction and visual design.
2. **Phase 2: MIDI Signals & Script Logic**
   - Set up Unity New Input System and MINIS plugin; write C# scripts to receive MIDI signals and handle value mapping.
3. **Phase 3: Generative Art & Scenography Integration**
   - Combine Particle Systems and Prefabs for modular deployment, completing the final audiovisual interactive performance.
